# Christine Geng - Portfolio

A responsive personal portfolio built with Next.js, React, and TypeScript. It includes an AI career twin powered by OpenRouter and NVIDIA Nemotron 3 Ultra.

## Run locally

```bash
npm install
```

Copy `.env.example` to `.env`, add your OpenRouter key, then start the app:

```bash
OPENROUTER_API_KEY=your_openrouter_api_key
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run typecheck
npm run test:e2e
npm run build
```
